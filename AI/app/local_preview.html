식품 챗봇 · 로컬 답변 확인

실제 챗봇 처리 경로의 최종 응답을 확인합니다. 앱 화면의 디자인이나 운영 데이터 연동을 재현하는 화면은 아닙니다.

가상 정보만 입력하세요. 제품 DB는 가상 새우과자·가상 우유 2개뿐이며 실제 식품 판단에 사용하면 안 됩니다. 제품 판정·비교는 현재 규칙 답변입니다. 일반 설명과 일부 레시피에서만 LLM이 사용될 수 있습니다.

설정 확인 중…

외부 모드에서는 질문, 이 대화의 최근 문맥·조건, 가상 프로필 및 필요한 자료가 설정된 외부 모델/검색 제공자에 전송될 수 있으며 API 비용이 발생합니다. LLM 호출과 검색 임베딩은 별도입니다. store:false는 제공자의 모든 로그 삭제를 뜻하지 않습니다.

프로필 변경 시 이전 조건과 문맥을 초기화합니다. 최대 20회 대화 후 새로 시작합니다.

질문·답변은 이 프로세스와 열린 화면의 메모리에만 보관합니다. 새로고침은 화면만 지우므로 문맥까지 지우려면 ‘새 대화’를 누르세요. 서버 종료 시 문맥이 사라집니다. 이 화면은 같은 브라우저의 여러 탭에서도 하나의 대화를 공유합니다.

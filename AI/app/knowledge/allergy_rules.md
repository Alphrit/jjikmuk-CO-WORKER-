# 알레르기 판단 규칙

## 근거와 우선순위

- ON 상태인 모든 프로필의 알레르기와 DB 제품의 원재료명·알레르기 표시를 비교한다.
- 한 프로필이라도 직접 충돌하면 전체 결론은 `피하기`다.
- 직접 충돌은 프로필 이름과 충돌 성분을 함께 표시하고 프로필별 결과도 제공한다.
- 같은 제조시설, 혼입 가능 등은 직접 함유와 구분해 `주의`로 표시한다.
- 원재료 또는 알레르기 표시가 부족하면 성분이 없거나 안전하다고 말하지 않는다.

## 현재 질문에서 새로 말한 알레르기

- 사용자가 현재 질문에서 “나는 새우 알레르기가 있어”처럼 분명히 말하면 그 질문에만 임시 적용한다.
- 저장된 프로필을 자동 수정하지 않는다.
- 답변에는 계속 적용하려면 설정에서 알레르기 정보를 변경하라는 안내를 제공한다.
- 누구의 알레르기인지 불분명한 다중 프로필 질문은 임의로 합치지 않고 대상을 확인한다.

## 결론

- 직접 함유: `avoid` / `conflict`
- 교차오염 가능성: `caution` / `cross_contact`
- 확인 가능한 표시에서 일치 성분 없음: `no_known_conflict` / `no_known_match`
- 제품 또는 표시 근거 부족: `check_required` / `unknown`

`no_known_match`는 안전 보증이 아니다.

## 중증 반응 예외

현재 식품 섭취 뒤 호흡곤란, 목·혀 부종, 의식 저하처럼 명확한 중증 알레르기 반응이 언급된 경우에만 고정 응급 안내를 먼저 제공한다. 과거 경험, 가정 질문, 일반 증상 설명은 응급 라우팅하지 않는다.

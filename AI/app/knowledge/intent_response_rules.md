# 지원 질문과 응답 흐름

## 제품 섭취 질문

“새우 알레르기가 있는데 새우깡 먹어도 돼?”처럼 묻는 경우 제품을 DB에서 식별하고 ON 프로필과 표시 성분을 비교한다. 결론, 충돌 성분, 근거 표시, 프로필별 결과 순서로 답한다.

## 성분·영양 질문

- 원재료와 알레르기 표시에서 특정 성분의 직접 함유와 교차오염 문구를 구분한다.
- 영양 수치는 기준량과 함께 그대로 설명한다.
- 높음·낮음이나 식이 적합성은 자체 임계치로 만들지 않는다.

## 추천·비교 질문

- 충돌 제품에는 같은 용도의 DB 대체 제품 2~3개를 자동 제안할 수 있다.
- 모든 ON 프로필의 알레르기 충돌 후보를 제외한다.
- 사용자가 요구한 식이 조건과 비선호 성분도 적용한다.
- 수치 비교는 같은 기준량끼리만 한다.
- 후보가 부족하면 실제 DB 후보 수만 보여주고 제품을 지어내지 않는다.

## 레시피 질문

- 요청 제품이 알레르기와 직접 충돌하면 원제품 레시피를 그대로 제공하지 않는다.
- 충돌 이유와 대체 제품을 먼저 제시하고, 대체 제품을 사용한 레시피를 제공한다.
- 사용자가 다른 레시피를 요청하면 이전 답과 겹치지 않는 레시피를 제안한다.
- 완성 레시피의 모든 재료를 활성 프로필 알레르기와 다시 대조한다.

## 미지원 질문

질환별 섭취 판단, 약물, 식품 변질·보관 판정, 범용 지식·시사·잡담은 지원 범위 밖이라고 짧게 안내하고 알레르기·식이·제품 질문 예시를 제시한다.
